## 6. Tech buzzwords (use carefully — stay accurate)

| Buzzword | Safe BD phrasing for NexusOne |
|----------|-------------------------------|
| **Cloud / web portal** | Modern browser-based portal — no desktop install for managers |
| **Role-based access (RBAC)** | Admin / manager / viewer + module entitlements |
| **JWT / secure session** | Enterprise login with protected routes |
| **MySQL-backed** | Structured operational database (users, tagging, Freezone) |
| **GIS-enabled** | Leaflet maps with polygon editing (Geoman) |
| **AI-assisted** | AI help on land tagging (not “fully autonomous farm AI”) |
| **Real-time dashboards** | Live command KPIs for farm and plant |
| **API-ready architecture** | Next.js route handlers — integrations scoped per deal |
| **Mobile-responsive** | Works on desktop and mobile browsers |
| **Multi-tenant ready narrative** | Module codes per user — confirm tenancy model per deployment |
| **Auditability** | Ledgers, docs, sale history for accountability |
| **Data-driven decisions** | Dashboards replace gut-feel Excel |

**Avoid claiming unless engineering confirms for that deal:** IoT sensor mesh, blockchain traceability, autonomous drones, SAP certified connector, offline-first native apps.

## 10. Call-opening scripts using buzz + plain English

**Farm CEO:**  
“Most estates run land in one Excel, labour in another, and sales in WhatsApp. NexusOne gives you a **single pane of glass** — GIS land portfolio, crop P&L, and sale pipeline — **farm to finance**.”

**Feedlot owner:**  
“Headcount without **ADG** and **cost to date** is vanity. We show **Ready for sale** and **per-animal margin** at live-weight exit.”

**Meat exporter:**  
“If your plant knows production but commercial can’t see **channel mix** and **pending invoices**, cash leaks. FML Command Center + client **Halal/E-Form** docs close that gap — **lairage to ledger**.”
